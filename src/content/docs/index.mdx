## Install

Two commands, and the native addon comes with the package. No Rust toolchain,
no build step, no postinstall download on your side.

<Tabs>
  <TabItem label="npm">
    ```sh
    npm install @sendust/ts
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```sh
    pnpm add @sendust/ts
    ```
  </TabItem>
  <TabItem label="yarn">
    ```sh
    yarn add @sendust/ts
    ```
  </TabItem>
  <TabItem label="bun">
    ```sh
    bun add @sendust/ts
    ```
  </TabItem>
</Tabs>

## At a glance

| Runtime | Version the project pins | Notes |
| --- | --- | --- |
| Node.js | `>=22.23.5` | None |
| Bun | `1.4.4` | None |
| Deno | `2.9.8` | `--allow-ffi --allow-read`, plus `--allow-net` if your code opens sockets |
| Native targets | seven | `linux-x64-gnu`, `linux-arm64-gnu`, `linux-x64-musl`, `linux-arm64-musl`, `macos-arm64`, `macos-x64`, `windows-x64` |

Anything outside those targets fails closed at `createTransport` with
`CONFIG_NATIVE_UNAVAILABLE`, naming the package you would need. The detail lives in
the [quick start](guide/quick-start/).
