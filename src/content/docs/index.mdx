## Install

Pick your package manager. The package ships the native addon as a per-platform
optional dependency, so there is no Rust toolchain and no build step on your side.

<Tabs>
  <TabItem label="npm">
    ```sh
    npm install @sendust/ts
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```sh
    pnpm add @sendust/ts
    ```
  </TabItem>
  <TabItem label="yarn">
    ```sh
    yarn add @sendust/ts
    ```
  </TabItem>
  <TabItem label="bun">
    ```sh
    bun add @sendust/ts
    ```
  </TabItem>
</Tabs>

## At a glance

| Runtime | Version the project pins | Notes |
| --- | --- | --- |
| Node.js | `>=22.23.5` | — |
| Bun | `1.4.4` | — |
| Deno | `2.9.8` | `--allow-ffi --allow-read`, plus `--allow-net` if your code opens sockets |
| Native targets | five | `linux-x64-gnu`, `linux-arm64-gnu`, `macos-arm64`, `macos-x64`, `windows-x64` |

Anything outside those targets fails closed at `createTransport` with
`CONFIG_NATIVE_UNAVAILABLE`, naming the package you would need. The detail lives in
the [quick start](guide/quick-start/).
